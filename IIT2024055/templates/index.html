(a)

Vulnerable Implementation

Located in app.py inside ping_vulnerable(). The route accepts arbitrary user input from POST body and directly formats it into a command string without sanitization, passing it to subprocess.check_output(..., shell=True).

(b)

Working Exploit Payload

Primary Payload: 127.0.0.1 & whoami

The ampersand (&) acts as a command separator in cmd.exe (or ; in bash). The system executes the ping, followed immediately by whoami. Because this is Variant 1 (In-Band), stdout of the chained command is captured and returned directly inside the JSON response.

(c)

Root Cause Analysis

Root Cause: User-supplied input is directly concatenated into a system shell command without sanitization or validation, and executed through an operating system shell interpreter (shell=True). The shell parses metacharacters as command control syntax rather than literal data.

(d)

Implemented Mitigation

Defense-in-depth: Parameterized execution using an argument vector with shell=False combined with strict allow-list input validation (verifying target strictly matches an IPv4/IPv6 address or RFC hostname). Malicious characters are rejected before execution or treated strictly as literal argument strings.

Alternative Defensive Strategies

Theoretical mitigations from lecture material

01

Avoid the Shell

Directly invoke binaries using system APIs (e.g., execve in POSIX, CreateProcess in Windows) or standard library network modules rather than passing strings through sh, bash, or cmd.exe. When no shell exists, metacharacters have no special parsing logic.

02

Parameterized Execution (Argument Vectors)

Pass command arguments as separate elements of an array (e.g., ["ping", "-c", "1", user_input]) with shell=False. The OS treats each vector entry strictly as literal data for that position, making command chaining syntactically impossible.

03

Allow-List Input Validation

Enforce strict syntactic rules using positive allow-lists rather than denylists. Validate inputs against strict data formats (e.g. IPv4/IPv6 parsers or RFC hostname regular expressions). Reject any input containing spaces, delimiters, or control characters before processing.

04

Principle of Least Privilege

Execute the web server process under a dedicated, unprivileged service account with minimal filesystem and OS permissions. Deny access to sensitive shells, administrative binaries, and write access outside designated application directories to bound damage if an injection occurs.
