# Adding a member's project

1. Create a branch for your module from the current main branch.
2. Create a top-level folder using your exact roll number. Keep your application, dependencies, tests, and evidence inside that folder.
3. Copy the [project README template](docs/PROJECT_README_TEMPLATE.md) into your folder as README.md. Fill it in with the commands and port you verified.
4. Add your ownership row and project guide link to the [group README](README.md). Use the variant agreed by the group.
5. Check that your app starts from a fresh clone and that its evidence links open.
6. Open a pull request for the group to review. If another project uses the same port, run the demos in sequence or document how to change the port.

The repository ignores local runtime databases, virtual environments, dependencies, and video files. Share the final group video link through the course submission process. [Group checklist](docs/SUBMISSION_CHECKLIST.md)
